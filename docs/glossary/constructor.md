# Constructor

The **constructor** runs once, when an :t[object]{#object} is made with `new`.
It has the same name as the :t[class]{#class} and no return type:

```java
public Bunny() {
  this.addCostume("bunny1_stand");
}
```

It does the setting up that *when green flag clicked* does in Scratch.
