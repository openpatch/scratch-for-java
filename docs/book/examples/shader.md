# Shader

An example showing how to use shaders on stage and sprite objects.

![shader example](/assets/shader.gif)

:::alert{info}

**On your own computer only.** Shaders are run by OpenGL, and there is no OpenGL
behind a web page. The [tutorials](/tutorials) and every page of the
[documentation](/reference) do run in the browser.

:::
