# Class

A **class** is a building plan. `public class Coin extends Sprite { ... }`
describes what every coin looks like and what it does, but it is not a coin yet.
The coins themselves are :t[objects]{#object}, made from the class with `new`.

A class has :t[fields]{#field} (what each object knows) and :t[methods]{#method}
(what each object can do). Class names start with a capital letter.
