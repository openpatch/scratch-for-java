# Pipes

An example with heavy use of the Pen.

![pipes example](/assets/pipes.gif)

:::alert{info}

**On your own computer only.** This project loads its backdrop and its music
from the folder next to the code, and a web page has no folder to read them
from. The examples that do run in the browser — the [tutorials](/tutorials) and
every page of the [documentation](/reference) — use built-in pictures and sounds
instead.

:::
