# Teacher notes

Prepare Studio on a school computer, both bundled library flavors, the course
ZIP, and a writable student folder. Import the pack while offline and run a
standard project and an NRW checkpoint before class. NRW projects include the
course-provided Abiturklassen; keep those files with the project.

The seven tutorials progress through sprites, animation, collisions, messages,
input, custom assets and stage switching. Plan roughly a lesson for each small
chapter and more time for the hedgehog game. Starters build from earlier code;
checkpoints provide a recovery point, not the student's final submission.

Use the Spielwerkstatt choices for independent mechanics, arrays and score
testing. Retain the Entwicklertagebuch and its questions about changes, testing
and reasons. Ask students to explain a decision before showing a checkpoint.

At the end of each lesson students save their Java folder or a project ZIP.
Have them reopen it and run one meaningful check. Browser storage stays on that
computer; download JSON or ZIP before switching devices. Studio imports both.

Transfer during the movement/collision lessons and record flavor, library and
browser revision. A compiling project still needs a behavior check. Avoid desktop
recording, file-system and Tiled APIs in projects intended for the browser.

Keep offline Markdown lessons and asset license notices. Hyperbook-specific
directives remain in the original lesson files; prepared Java projects and assets
are directly usable without serving the book.
