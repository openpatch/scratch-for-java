# Sprite

A **sprite** is a character or object on the :t[stage]{#stage}: the bunny, a
coin, a rock. It has :t[costumes]{#costume}, a position and a direction. In Java
you write a class that `extends Sprite` and put an :t[object]{#object} of it on
the stage with `this.add(new Bunny());`.
