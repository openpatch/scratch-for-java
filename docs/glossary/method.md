# Method

A **method** is something an :t[object]{#object} can do, like a block in
Scratch: `this.move(10);` calls the method `move`. You can write your own methods
too, to give a sequence of steps a name.

Some methods are called by the library for you: `run()` in every
:t[frame]{#frame}, `whenKeyPressed` when a key is pressed.
