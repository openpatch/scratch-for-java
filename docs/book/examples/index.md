# Examples

Finished projects to play with, read and take apart. Almost all of them run right
here in the browser: open one, press ▶, then change something and see what
happens. Each page has the whole source code.

## Start here

Small projects that use one or two ideas from the [tutorials](/tutorials).

| Example | What it shows |
| --- | --- |
| [Cat](/examples/cat) | A sprite that walks, bounces off the edges and leaves stamps behind |
| [Glide](/examples/glide) | Sprites sliding to a new place with `glide()` |
| [Quiz](/examples/quiz) | Asking questions with `ask()` and reacting to the answers |
| [Clock](/examples/clock) | Reading the time of your computer |
| [Volume](/examples/volume) | Turning sounds up and down |
| [Random Dot](/examples/random-dot) | Drawing with a timer and random positions |
| [Timed Dot](/examples/timed-dot) | Several timers running at different speeds |
| [Rainbow Vine](/examples/rainbow-vine) | Following the mouse |

## Games

Whole games, built like the later tutorials: several sprite classes, a score,
and sometimes several screens.

| Example | What it shows |
| --- | --- |
| [Coin Collector](/examples/coin-collector) | Walking, jumping and collecting, with built-in pictures only |
| [Cat Platformer](/examples/cat-platformer) | A platformer with the Scratch for Java cat, enemies and a goal |
| [Donut IO](/examples/donut-io) | Switching between stages, and many sprites at once |
| [Robot](/examples/robot) | A stage and a sprite class of their own, with hitboxes shown |
| [Sensing](/examples/sensing) | Touching the mouse pointer, and hitboxes of your own |

## Going further

Projects that use more of Java or more of the library: the pen, text,
vectors, shaders and Tiled maps.

| Example | What it shows |
| --- | --- |
| [Timer](/examples/timer) | Every method of the timer side by side |
| [Pipes](/examples/pipes) | Drawing with many pens at once |
| [UI](/examples/ui) | Stretching pictures for panels and bars, and a custom mouse pointer |
| [Shakespeare](/examples/shakespeare) | An evolutionary algorithm that writes a line of Shakespeare |
| [Smart Rocket](/examples/smart-rocket) | Rockets that learn to reach a target, with `Vector2` and `Random` |
| [Shader](/examples/shader) | Small graphics programs that change how things are drawn |
| [Stress Test](/examples/stress-test) | How many sprites can your computer show at once? |
| [Tiled](/examples/tiled) | Levels drawn in the Tiled map editor (only on your own computer) |
